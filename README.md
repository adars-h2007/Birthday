# Birthday

A single-page birthday wish website, built with HTML and designed to be shared as a link.

**Live site:** https://birthday-orcin-eight-89.vercel.app

## About

A small personal project: one web page made as a birthday greeting. It's a simple example of building and publishing a static page from start to finish.

## Project structure

```
.
├── hbdsis.html    # The birthday page
└── README.md
```

## Run locally

No installation is needed.

```bash
git clone https://github.com/adars-h2007/Birthday.git
cd Birthday
```

Then open `hbdsis.html` in your browser.

## Deploy

The page is static, so it can be hosted anywhere. It is currently deployed on **Vercel**: import the repository and deploy with the default settings.

## Tech used

- HTML5
- Vercel (hosting)
